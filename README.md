# 运动会 · 教师专场问答（静态网页版）

纯静态网页，双击 `index.html` 就能玩，传到 GitHub Pages 上老师直接打开链接即可。
**不用装任何东西，不用联网，不用服务器。**

---

## 一、项目结构

```
teacher-quiz/
├── index.html      页面骨架          ❌ 不用改
├── style.css       样式              ❌ 不用改
├── app.js          程序逻辑          ❌ 不用改
├── questions.js    【所有可改的内容】 ✅ 只改这个
├── images/         题目配图放这里     ✅ 放图片
└── README.md       本说明
```

> 想改任何文字、颜色、题目、分数、称号，全部在 `questions.js` 里，其余三个文件不用碰。

---

## 二、questions.js 里有什么

| 区块 | 管什么 |
|---|---|
| `QUIZ_CONFIG` | 学校名、标题、副标题、题量 30、时长 20 分钟、提醒时间点、**选项是否打乱** |
| `QUIZ_ADMINS` | **管理员名单**（输入这些名字进入管理员模式） |
| `QUIZ_TEXTS` | **页面上出现的每一句话**：按钮、提示、免责声明、成绩单文案 |
| `QUIZ_RANKS` | 段位称号（多少分对应什么称号） |
| `QUIZ_THEMES` | 5 套主题配色（可改色 / 加主题 / 删主题） |
| `QUESTION_BANK` | 题库 |

## 三、加题（最常用）

打开 `questions.js`，找到 `window.QUESTION_BANK = [ ... ]`，
在方括号里**复制一段下面的模板粘贴进去**，改内容就行：

```js
{
  contentTag: "整活题",        // 内容标签：整活题 / 正经题 / 知识题 / 常识题
  type: "单选",                // 题型：单选 / 多选 / 不定项
  secretTag: "",               // 彩蛋标签：填了就把上面两个标签整个盖掉（留空=正常显示）
  text: "这里写题干",
  image: "",                   // 要用图就写 "images/q1.jpg"，不用图留空 ""
  options: [
    { text: "选项A", score: 5,  feedback: "选A之后单独弹给他的话" },
    { text: "选项B", score: -1, feedback: "选B之后单独弹给他的话" },
    { text: "选项C", score: 0,  feedback: "选C之后单独弹给他的话" }
  ],
  comment: "提交后显示的整体评价，可留空"
},
```

注意：
- 每段之间要有**逗号**，最后一段后面不要逗号
- **选项数量随便写，2～6 个都行**（题库里已有 2、3、4、5、6 个选项的题，程序都能处理）
- **想出"不选才是最佳答案"的题**：把选项分值全写成负数，题干里注明"（可以不选）"。
  不选提交记 0 分，自然就是最高分（题库里已有 2、3、4、5、6 个选项的题，程序都能处理）
- **选项顺序每位老师各自随机打乱**，不会让 A 总是最高分。打乱结果在开局抽题时确定，之后刷新、续答、回顾都保持一致。
  想关掉打乱、按题库原顺序显示，把 `QUIZ_CONFIG` 里的 `shuffleOptions` 改成 `false`
- 题库里写选项时可以随便排，不用刻意把高分项藏在后面
- `score` 可以正可以负；**本题得分 = 所选选项分值相加**
- 多选题选了几个算几个的分，可能被扣成负分，总分也允许为负
- 题数不足 30 时会弹窗提醒，点"确定"也能照常玩（方便边加边测）

### 图片怎么用
1. 图片放进 `images/` 文件夹，文件名建议英文数字，如 `q03.jpg`
2. 题目里写 `image: "images/q03.jpg"`
3. 图片显示在题干**上方**，点一下可放大

## 四、姓名与管理员模式

### 姓名
开局页必须先填名字才能开始。名字会显示在成绩单、成绩单图片、文字版和导出的 CSV 里。
名字只存在本机，不上传。下次打开会自动填好上次的。

### 管理员
在 `QUIZ_ADMINS` 里列名字，输入其中一个（忽略大小写和空格）就会在开局页出现管理员面板：

```js
window.QUIZ_ADMINS = ["林钰航","lyh","xyf","夏毅夫","邓瑞","管理员0","X_thinker"];
```

管理员专属功能：

| 功能 | 怎么用 |
|---|---|
| **查看全部题目与反馈** | 开局页或成绩单点「查看全部题目与反馈」，列出每题题干、每个选项的分值和反馈文案，方便出题人校对。**答题前别让老师看到** |
| **调整时间限制** | 开局页填分钟数，或点「不限时」关掉倒计时（倒计时显示"不限时"，不会强制收卷） |
| **多次做题** | 成绩单页有「再来一套（管理员）」，直接开新卷，不用清记录 |
| **作答回顾** | 成绩单页「查看本次作答回顾」，逐题看自己选了什么、得多少分 |
| **历史成绩** | 成绩单页自动列出本机最近 30 次的成绩记录 |

普通老师不受影响：看不到管理员面板，答完只能看到自己的成绩单。

> 想加管理员就往数组里加名字，想取消某人就删掉那一项。

## 五、改文案

`QUIZ_TEXTS` 里，等号右边的引号内随便改。带 `{xxx}` 的是占位符，程序自动替换，别删花括号里的词。

例如改倒计时提醒：
```js
timerToast: "⏰ 还剩 {m} 分钟，老师们加油～",
```

改免责声明（上面严肃、下面轻松，数组里一句一行）：
```js
disclaimerSerious: [ "第一句", "第二句", "第三句" ],
disclaimerFunny:   [ "第一句", "第二句", "第三句" ],
```

## 六、改主题 / 加主题

`QUIZ_THEMES` 里每套主题长这样，改十六进制颜色即可：

```js
grape: {
  label: "紫气东来",                       // 右上角菜单里显示的名字
  vars: { bg1:"#F3E7FA", bg2:"#E6CDF2", panel:"#FFFFFF", ink:"#2A0B38",
          sub:"#7A5A88", primary:"#700F96", primaryInk:"#FFFFFF", soft:"#EFDCF8",
          line:"#E3CFEE", ok:"#1E8E5A", bad:"#C62E47", radius:"16px", font:"..." },
  png: ["#700F96", "#C06BD8"]              // 成绩单图片的背景渐变
},
```

**加一套**：复制整段，改个英文键名（如 `mytheme`）和 `label`，右上角菜单会自动多一项。
**删一套**：把那一段整个删掉即可。

字段含义：

| 字段 | 含义 | 字段 | 含义 |
|---|---|---|---|
| `bg1` `bg2` | 页面背景渐变 | `primary` | 主色（按钮、标签） |
| `panel` | 卡片底色 | `primaryInk` | 主色按钮上的字 |
| `ink` | 主文字 | `ok` `bad` | 得分正 / 负的颜色 |
| `sub` | 次要文字 | `radius` | 圆角大小 |
| `soft` | 浅色底（选项、反馈框） | `font` | 字体 |
| `line` | 边框线 | `png` | 成绩单图片渐变 |

## 七、功能一览

- **开局页**：填名字 → 大标题 + 开始答题 + 宇宙安全免责声明（上严肃下轻松）
- **答题页**：标签 → **题号导航** → 配图 → 题干 → 选项 → 提交 / 瞄一眼
  - 单选 / 多选 / 不定项自动切换交互
  - 出题人设了 `secretTag` 的题，标签会被整活标签盖住，提交后才揭晓真实标签
  - **一个选项都不选也能提交**，有时不选才是最佳答案（题库里就有这样的题）
  - 未选任何选项时按钮会显示"一个都不选，直接提交"，防误点
- **即时反馈**：每个选中选项的专属文案 + 本题加减分 + 累计总分
- **总分徽章**：顶栏实时显示当前总分，得分变化时数字会跳一下
- **回看已答题**：点顶部的绿色题号可以回看任意已答的题，看到当时的选择和反馈，
  但**改不了答案**。深色格子是当前题，灰色是还没答的（点不了）
- **瞄一眼答案**：每道题下方有个虚线按钮，旁边写着"点了就扣分，而且不给答案"
  - 管理员点开：直接看本题所有选项的分值和反馈，不扣分
  - 老师点开：**只给题干和选项文字，不给分值、不给反馈、不给评价**，而且扣分递增
    —— 第 1 次扣 1 分，第 2 次扣 2 分，第 3 次扣 3 分，以此类推（整场累计，不是每题重新计）
  - 瞄过的次数和总扣分，会显示在成绩单上
- **计分**：每题分值由选项决定，可正可负，总分可以是负数
- **抽题**：题库随机抽 30 道，同一人不重复，顺序打乱；每题选项顺序也各自打乱
- **倒计时 20 分钟**：固定在顶部，剩 10/5/1 分钟弹提醒，到点强制收卷
- **断点续答**：每答一题自动存本机，刷新 / 误关 / 重启浏览器都直接接着答
- **成绩单**：姓名 + 总分 + 段位称号 + 用时，四种导出
  - 📷 成绩单图片 PNG（纯本地绘制，断网也能导）
  - 📋 复制文字版（直接粘贴到群里）
  - 📊 答题明细 CSV（Excel 直接打开，方便统计每题作答）
  - 🗂 原始数据 JSON
- **选项随机打乱**：每位老师看到的选项顺序都不同，A 不总是最高分
- **管理员模式**：查看题目反馈、调时间、多次做题、作答回顾、历史成绩
- **5 套主题**：右上角"主题"随时切换，选择会记住

## 八、发布到 GitHub Pages（三步）

1. 在 GitHub 新建仓库，把 `index.html`、`style.css`、`app.js`、`questions.js`、`images/` 一起传上去（网页上直接拖文件即可）
2. 仓库页面 → **Settings → Pages** → Source 选 `main` 分支 / 根目录 → Save
3. 等一两分钟，会得到形如 `https://用户名.github.io/仓库名/` 的网址，发给老师即可

> 本地测试：直接双击 `index.html` 用浏览器打开，功能完整（含导出图片）。
> 想清空记录重新答，成绩单页面最下面有"清掉记录，再答一次"。

---

## 九、小提醒

- 老师用**各自的电脑**打开才互不影响（数据存在各自浏览器里）
- 换电脑、换浏览器、清缓存 = 记录没了，提醒老师答完先导出成绩单
- 强制收卷时未答的题记 0 分，导出明细里会标"未作答"
